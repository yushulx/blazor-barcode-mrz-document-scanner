# Blazor Examples for Barcode, MRZ and Document Scanning
This project demonstrates how to utilize the Dynamsoft Capture Vision SDK for detecting **1D/2D barcodes**, **documents**, **MRZ (Machine Readable Zone)**, and more in Blazor applications. Built on Dynamsoft Capture Vision Bundle 3.6, Dynamsoft Document Viewer 5.0 and Dynamic Web TWAIN 19.4.

## Usage
1. Run the app:

    ```
    dotnet run
    ```

2. Open the app, paste your [Dynamsoft Capture Vision trial license](https://www.dynamsoft.com/customer/license/trialLicense/?product=dcv&package=cross-platform) key into the activation panel on the Home page and press **Activate SDK**. A 24-hour SDK trial key is pre-filled, so you can also just press the button.

    ![blazor barcode reader and scanner](https://www.dynamsoft.com/codepool/img/2024/09/dotnet-blazor-barcode-qrcode-scanner.png)
